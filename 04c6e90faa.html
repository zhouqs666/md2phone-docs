md2phone · 把 Markdown 放进手机

更新于 2026-10-02 01:39 · 约 11 分钟 · 第 2/8 篇

电脑上的 .md 文档 → 手机桌面图标、App 般的阅读体验、内容随电脑同步更新。 纯静态产物（一个 site/ 文件夹），不依赖任何付费服务；文档不经过本工具之外的第三方处理（部署到你自己选的托管上）。

两种用法

用法 A · 单文件版（第一版：不依赖任何第三方，今天就能用）

1. 把 .md 文件放进 docs/ 文件夹（删除 = 从文件夹移除）
2. 双击 sync.command（或终端运行 python3 build.py）
3. 把生成的「文档库.html」发到手机（微信 / 邮件 / 数据线都行）

手机上怎么打开： - iPhone：微信里点开文件可直接读；或长按 → 存到「文件」App → 点开即读 - Android：微信里点开 → 右上角「…」→ 用浏览器打开（或文件管理器 → Chrome）

文档更新了：重跑第 2 步，把新的「文档库.html」再发一次（旧的删掉即可）。

特点：一个文件装下全部文档 + 目录 + 字号调整，不需要联网、不注册任何服务；代价是没有自动同步（更新 = 重发文件），桌面图标暂缺（想要时用 A2 或 B）。

用法 A2 · 局域网版（不要第三方，但要「桌面图标」）

双击「局域网分享.command」（或终端运行 python3 build.py --serve --lan），终端会显示一个形如 http://192.168.x.x:8787/ 的地址：

  1. 手机连到和电脑同一个 WiFi，浏览器打开该地址 → 文档列表，点文档即读；
  2. iPhone：Safari 打开 → 分享 → 「添加到主屏幕」→ 桌面图标，点开全屏； Android：Chrome 菜单 → 「添加到主屏幕」；
  3. 文档更新后：双击 sync.command 重建 → 手机刷新即见最新（同 WiFi 内近似自动同步）。

前提与代价：电脑开机、手机同 WiFi，离开家打不开；macOS 首次运行若弹防火墙询问，点「允许」。

用法 A3 · 安卓 App（文档库.apk）：真 App 形态

  1. 安装（一次）：把 文档库.apk 传到手机点开安装（首次需允许「安装未知应用」）；桌面出现「文档库」图标，点开即文档列表，出厂已内置全部文档，离线可读；
  2. 日常更新·方式一（联网，一键）：App 启动时会静默比对版本，有新内容弹窗询问；也可随时点右上角菜单「从网站拉取最新」→ 进度对话框内自动比对版本 → 有更新即下载并加载（无更新提示「已是最新」）；前提：电脑侧已用「自动同步.command」确认发布上网站；
  3. 日常更新·方式二（离线可用，约 20 秒）：电脑 python3 build.py → 把新的 文档库.html 发到手机 → 菜单「导入文档库」选中该文件即完成（App 会校验文件确实为整库快照，选错会提示）； ⚠️ 导入的是 文档库.html 这个整库文件（里面已打包全部文档的最新版本），不是 .md 原文——App 不解析 md；改了几篇都只需发这一个文件；
  4. 「恢复内置」：菜单里一键回到出厂文档；
  5. 阅读位置记忆：每个文档自动记住读到的位置，重开即从上次处继续（存在手机本地，不跨设备）；
  6. 文档里的外链（网页/邮件/电话）点击后交给系统浏览器等应用打开，不会困在 App 里。

iPhone 不在此用法内（苹果不允许直接装安装包），用 A / A2 / B。

发布通道已全自动打通（2026-10-01 端到端验收：新增 63s / 删除 73s 反映到公网）：

文档库网址：https://zhouqs666.github.io/md2phone-docs/

  • 电脑侧：双击「自动同步.command」→ docs/ 文件一变 → 自动构建 → 弹窗确认（发布 / 本次跳过 / 本会话不再询问）→ 约 1 分钟后手机刷新即见最新；
  • 手机侧（一次性）：浏览器打开网址 → Android：Chrome 菜单「添加到主屏幕」；iPhone：Safari 分享「添加到主屏幕」→ 桌面图标，全屏 App 体验；
  • 托管为 GitHub Pages（仓库 zhouqs666/md2phone-docs，public——免费 Pages 的前提），已加 noindex 防搜索引擎收录；
  • 已知边界：GitHub Pages 有 ≤10 分钟 CDN 缓存（不可配置），对时效极敏感时用用法 A3 的「文档库.html 导入」（秒级）；停用：GitHub 网页进仓库 Settings → Delete。

手机端一次性设置（装到桌面，用法 A2 / B）

  1. 手机浏览器打开文档库网址（必须 https:// 开头，安装图标和离线缓存都依赖它）；
  2. Android（Chrome）：右上角菜单 → 「添加到主屏幕 / 安装应用」； iPhone（Safari）：底部分享按钮 → 「添加到主屏幕」；
  3. 桌面出现「文档库」图标，点开即全屏阅读，断网也能读看过的文档。

阅读页：顶栏 ‹ 返回列表 · 标题（滚到深处自动切换为当前小节名）；轻点正文空白处唤出/收起控制层——顶栏与底部工具条（☰ 目录 · Aa 字号 · 🔍 查找）一起进出，读到一半随时可用，不必滚回篇首；首次进入沉浸阅读会有一次性手势提示。目录抽屉打开即定位当前小节并显示已读百分比。字号五档预设（14/17/20/23/26px，当前档高亮，「默认」键一键回 17），改字号阅读位置不跳动；外观三档：跟随系统/浅色/深色；「长代码自动换行」默认开（面板可关回横向滑动保结构），超长代码块限高内滚。🔍 页内查找（高亮 + 上/下一个）。宽表格先自适应收窄装下，装不下才容器内滑动（两缘渐隐提示）；下滑阅读时控制层自动隐退、上滑唤出；深滚动时右下角悬浮「↑ 回到顶部」。

正文还有：标题下元信息行（更新时间/时长/序号）、开篇文档头卡（版本/定位逐行呈现）、顶部阅读进度条、代码块一键复制（独立工具位不遮内容）、表格与代码块两缘渐隐滑动提示、图片点击放大、底部「较新一篇 / 较早一篇」切换。首页：搜索框（标题+正文，命中片段高亮）· ⇅ 排序切换 · 「继续阅读」横幅 · 列表滚动位置记忆。PWA 有新内容时弹「内容已更新」提示条。

第一次部署（用法 B 已完成 ✅，以下仅备查；三选一，都是免费档）

当前已配置：GitHub Pages + publish_github.py 全 API 发布 + 自动同步.command 全自动同步。 备选方案（如需更换托管）：

推荐 A，最省事且可全自动：

A. Netlify（推荐）

npm install -g netlify-cli     # 需已安装 Node.js
netlify login                  # 首次注册/登录
# 之后每次同步自动发布（全自动：存盘 → 上线）：
DEPLOY_CMD="netlify deploy --dir site --prod" python3 build.py --watch

不想装命令行：打开 app.netlify.com/drop，把 site/ 文件夹拖进去，得到网址（以后每次更新需手动再拖一次，半自动）。

B. GitHub Pages：建仓库，把 site/ 内容推到 gh-pages 分支，仓库设置里开启 Pages。更新 = 把 site/ 重新提交推送。

C. Cloudflare Pages / Vercel：连接 GitHub 仓库自动部署，效果同 A。

原理说明：docs/ 是唯一内容来源。构建把 md 转成手机友好的静态页面（含 PWA 清单与 Service Worker）；托管只是把 site/ 放上互联网。手机端每次打开都先取最新（network-first），取不到才用本地缓存，所以「电脑更新 → 重建 → 手机刷新即最新」。

全自动 vs 半自动

方式 操作 适用
半自动 双击 sync.command 偶尔更新；未配置发布时用本地预览
全自动 DEPLOY_CMD="netlify deploy --dir site --prod" python3 build.py --watch 挂在终端里，保存文档几秒后自动上线

build.py 参数：--watch 监听 docs/ 与 assets/ 自动重建；--serve 本地预览 http://localhost:8787 （仅供电脑检查，手机安装需 HTTPS 托管）。

常见问题

  • 手机上没出现「安装」提示？ iPhone 需在 Safari 里用「分享 → 添加到主屏幕」手动添加；网址必须是 https。
  • 删除的文档手机上还能看到？ 列表刷新后即消失；已缓存的正文副本会在下次联网刷新后被清掉（Service Worker 按构建版本清理旧缓存）。
  • 「从网站拉取最新」之后内容反而变旧了？ 拉取拉的是「网站上的版本」——如果电脑改完文档还没发布（双击 自动同步.command 确认发布），网站上就是旧的，拉取会用旧构建替换手机内容。先发布再拉取即可；拉错了就用菜单「恢复内置文档」回滚。
  • 重装/更新 App 后还是旧内容？ App 优先加载之前「导入文档库 / 从网站拉取最新」留下的快照，覆盖安装 APK 不会覆盖它。菜单「恢复内置文档」回到出厂内容，或直接「导入文档库」选新的 文档库.html。想确认加载的是哪份内容：Aa 设置面板或文章末尾有「内容指纹 + 来源」标识。
  • 文档里表格太宽？ 表格先自适应收窄（缩字号/紧边距）尽量装下；实在装不下的在卡片容器内左右滑动，两缘有渐隐提示。代码块默认自动换行，可在阅读工具条 Aa 面板里改回「保结构横向滑动」。
  • 想换图标/名字？ 改 build.py 里的 manifest 与 make_icons()，或直接替换 site/assets/ 下的图标后重建。

开发者
